01 / 项目全貌

这个项目现在到底是什么

它已经不是“只有一个 MLP 的小练习”了。现在它同时包含三条路线： 一条是传统前馈网络 + MNIST；一条是最小 Transformer / 字符级语言模型实验链路； 还有一条是现代训练栈 —— Adam / AdamW / RMSProp、学习率调度、梯度裁剪、GELU 激活等。

MLP 路线

核心类是 NeuralNetwork。它负责多层全连接、激活函数、损失函数、优化器、参数初始化、训练与预测。

  • 适合理解前向传播 / 反向传播
  • 适合理解权重、偏置、loss、梯度下降
  • 示例程序是 src/demo/mnist

Transformer 路线

核心模块位于 src/deeplearning/transformer。已经有 embedding、位置编码、layer norm、self-attention、block、encoder、decoder、字符 tokenizer、dataset、语言模型与 loader。

  • 支持 encoder / decoder 主干
  • 支持训练、保存/加载、greedy 与采样生成
  • 示例程序是 src/demo/transformer_char

现代训练栈

五种优化器 (SGD / Momentum / RMSProp / Adam / AdamW), 四种 LR 调度 (Step / Exp / Cosine / Warmup+Cosine), 梯度裁剪, 以及 LeakyReLU、GELU 等现代激活.

  • 训练全程支持 set_random_seed 复现
  • L2 weight decay 一键开关
  • 对比 demo: src/demo/optimizer_bench

为什么它很适合学习

因为它不是巨型框架，没有几十层抽象。你能顺着文件一路读到核心公式和数据流。

  • 更接近“原理版”而不是“工业封装版”
  • 适合理解 attention 在语言模型里怎么用
  • 适合把概念和具体 C++ 代码对应起来

02 / 神经网络路线

Attention 不是凭空出现的，它是神经网络演化出来的

如果你直接从 Transformer 开始，很容易只记住一堆名字：Q、K、V、softmax、multi-head。 但真正的理解通常来自一条很朴素的路线：神经元 -> 多层网络 -> 梯度下降 -> 序列建模 -> Attention。

1

先有神经元

一个神经元本质上做的事很简单：把几个输入按权重加起来，再过一个非线性函数。

2

再有多层网络

把很多神经元堆起来，就得到 MLP。它会一层一层提取更复杂的特征。

3

再有训练

网络做错了，就通过 loss 衡量错误，再通过反向传播把“哪里错了”传回每个参数。

4

遇到序列问题

当输入不再是固定向量，而是一个句子、一个 token 序列，旧的 MLP 方式就不够自然了。

5

Attention 出场

它解决的核心问题是：当前 token 到底应该重点看序列里的谁？

前向传播时，最常见的模式是先做线性变换，再过激活函数。反向传播时，则会切到梯度链式法则。

链式法则拆解

dL/dW = dL/dy * dy/dz * dz/dW

还没进入反向传播时，这里会显示“当前没有梯度拆解”。

链式法则的意思不是“突然多出很多公式”，而是把“总误差对某个参数的影响”拆成一段一段局部影响，再连乘起来。

数值流动

x = [1.00, 0.50] -> h = [0.42, 0.73, 0.18] -> y = [0.81]

梯度流动

dL/dy = [-0.19] -> dL/dh = [-0.08, 0.03, 0.11] -> dL/dx = [0.04, -0.02]

05 / 现代训练栈

把 SGD 升级成 Adam、加上调度器和裁剪，模型才训得动

前向 / 反向只是 "怎么算梯度"；真正决定 "训不训得收敛、训得多快、训完是不是过拟合" 的, 是优化器、学习率调度、参数初始化和梯度裁剪. 这一节把项目里已有的训练设施梳理一遍.

优化器 (Optimizer)

src/deeplearning/optimizer/ 提供五种:

  • SGD — 经典随机梯度下降, w -= lr * g
  • Momentum — 带动量, 在峡谷型 loss 上更稳
  • RMSProp — 按梯度平方滑动平均自适应步长
  • Adam — 一阶 + 二阶矩 + bias correction, 现代默认
  • AdamW — 解耦的 weight decay, Transformer 标配

学习率调度 (LR Scheduler)

src/deeplearning/lr_scheduler/ 让 lr 在训练过程中动态变化:

  • StepDecayLR — 每 N 步乘 gamma
  • ExponentialDecayLR — 每步乘 gamma
  • CosineAnnealingLR — 余弦退火到 min_lr
  • WarmupCosineLR — 先线性升温, 再余弦退火

注入方式: net.set_lr_scheduler(std::make_shared<CosineAnnealingLR>(...)).

梯度裁剪 + L2

防止梯度爆炸 / 控制权重大小, 训 Transformer 几乎必备:

  • set_gradient_clip_norm(1.0) — 全局 L2 范数裁剪
  • set_gradient_clip_value(0.5) — 逐分量绝对值裁剪
  • optimizer->set_weight_decay(1e-4) — L2 weight decay, Adam 走耦合, AdamW 走解耦, bias 不衰减

激活函数家族

src/deeplearning/activate/ 新增了两个现代激活, 在 神经元实验台 里可以直接切到它们看输出曲线:

  • LeakyReLU — 负半轴留个小斜率 (0.01), 缓解 dead ReLU
  • GELU — x · Φ(x), BERT / GPT 类标配, 比 ReLU 平滑, 训练 Transformer 收益明显

可复现性

所有随机参数初始化器 (Xavier / He / Uniform / Normal) 支持 set_seed(int):

  • set_random_seed(42) 后, 同样代码同样结果
  • seed 会自动透传给 param_init
  • 训练 / 评估 / 对比都能 bit-wise 复现

对比 demo

src/demo/optimizer_bench 在同一 MLP 上跑所有 optimizer, 输出 wall-clock 和 acc:

  • ./bin/optimizer_bench --skip-mnist — 合成数据快速过
  • ./bin/optimizer_bench --steps 3000 --batch 64 — MNIST 实测
  • MNIST 结果: Adam 系列普遍 96%+, SGD 95.7%

把上面这些拼起来 — 一个 "现代" 训练循环长这样

net.set_random_seed(42);
net.set_param_init_function(PARAM_INIT_HE);
net.set_activate_function(ACTIVATE_GELU);
net.set_optimizer_function(OPTIMIZER_ADAMW);
net.optimizer_function()->set_weight_decay(1e-4);
net.set_gradient_clip_norm(1.0);
net.set_lr_scheduler(std::make_shared<WarmupCosineLR>(1e-3, 500, 10000));
net.Train(data, target, callback, 10000, 64);

可以看到, 这跟 PyTorch 里 "Adam + cosine + clip + weight decay" 那套写法 概念上完全对得上 — 只是接口名是 C++ 而已. 真正理解了上面几个组件, 读 PyTorch / JAX 训练脚本就不用再死记参数名了.

06 / 为什么需要 Attention

传统网络遇到序列时，真正难的不是“有很多词”，而是“相关词离得很远”

比如一句话里，当前词要不要关注另一个词，取决于语义关系，而不是物理距离。 这也是为什么 Transformer 的关键不是“更深”，而是“让 token 之间直接互相看”。

没有 Attention 时

信息往往要沿着一条长链慢慢传，距离一远，就更容易丢失或被稀释。

你可以把它想成“传话游戏”：中间经过很多站，原始信息越来越模糊。

有 Attention 时

当前 token 可以直接看整个序列，并自己决定谁重要、谁次要。

你可以把它想成“开会时先扫一眼全场，再决定该听谁”。

一句话记忆： Attention 的本质不是“更复杂的矩阵运算”，而是“给当前 token 一种主动分配注意力的能力”。

再往前一步：为什么要多头（Multi-Head）

单头 attention 只有一种“关注视角”。多头 attention 的想法是： 同一个 token，在不同子空间里可以学不同关系。 一个头可能更偏向“谁是主语”，另一个头可能更偏向“动作和宾语”，还有一个头可能更关注“位置或局部结构”。

08 / 代码映射

概念和这个仓库的 C++ 代码怎么一一对应

学 attention 最容易卡住的地方，就是“听懂了课，但不知道代码里哪一块对应哪一个概念”。 这一节就是专门做这个映射。

1. 神经网络基础

src/deeplearning/neural_network.*

这里是理解训练最好的入口。你会看到参数初始化、前向传播、反向传播、优化器更新这些最基础的东西。

2. 优化器家族

src/deeplearning/optimizer/

SGD / Momentum / RMSProp / Adam / AdamW 都在这里, 都实现了同一个 OptimizerFunction 接口, 易于对比与替换.

3. 学习率调度器

src/deeplearning/lr_scheduler/

Step / Exp / Cosine / WarmupCosine, 通过 set_lr_scheduler 注入, 训练每个 step 自动应用.

4. 激活与初始化

activate/ + param_init/

5 种激活 (Sigmoid / ReLU / Tanh / LeakyReLU / GELU), 5 种 init (Zero / Uniform / Normal / Xavier / He, 全部支持 seed 复现).

5. Self-Attention 核心

src/deeplearning/transformer/self_attention.*

这里能直接看到 Q/K/V 投影、score 计算、softmax、加权求和，以及 backward 的梯度链路。

6. Transformer Block

src/deeplearning/transformer/transformer_block.*

这里把 attention、residual、layer norm、FFN 组合起来，你会看见“一个完整 block 到底长什么样”。

7. 语言模型闭环

src/deeplearning/transformer/mini_transformer_lm.*

这里对应训练、评估、greedy 生成、sample 生成，是把 attention 变成“能出字”的关键一层。

8. 数据与词表

character_tokenizer.* / character_dataset.*

它们把原始字符串切成 token，并进一步切成 next-token 训练样本。

9. 可运行 demo

src/demo/{mnist,transformer_char,optimizer_bench}/

三个 demo: MNIST 手写识别, 字符级语言模型, 不同 optimizer 在同一架构下的对比.

如果你想看 MLP 的训练骨架

src/deeplearning/neural_network.cpp

  • Train(...)：训练总入口, 支持 scheduler / 梯度裁剪 / mini-batch
  • ForwardPropagationBatch(...)：批量前向, 同时记录 pre-activation
  • BackPropagationBatch(...)：批量反向, 累加梯度
  • ClipGradients(B)：可选的 by-norm / by-value 裁剪
  • ApplyGradient(B)：调 optimizer->BeforeStep + 逐参数更新

如果你想看 Adam / AdamW 怎么实现

src/deeplearning/optimizer/adam_optimizer.cpp

  • BeforeStep()：推进 step 计数, 算 bias correction
  • CalcChangeValue(...)：m / v 滑动更新 + 自适应步长
  • adamw_optimizer.cpp：继承 Adam, 但把 weight decay 解耦出来

如果你想看学习率调度怎么写

src/deeplearning/lr_scheduler/*.cpp

  • StepDecayLR::GetLR(step) — base * gamma^(step/step_size)
  • CosineAnnealingLR::GetLR(step) — 余弦退火公式
  • WarmupCosineLR::GetLR(step) — 线性升温 + 余弦, Transformer 标配

如果你想看 attention 的核心机械结构

src/deeplearning/transformer/self_attention.cpp

  • Forward(...)：Q/K/V -> score -> softmax -> weighted sum
  • Backward(...)：把输出梯度一路传回 Q/K/V 与投影权重
  • last_attention_weight()：读取最近一次注意力权重

如果你想看完整 Transformer block

src/deeplearning/transformer/transformer_block.cpp

  • Forward(...)：attention -> residual -> norm -> FFN -> residual -> norm
  • Backward(...)：把梯度沿着 block 结构反向拆开

如果你想看字符级语言模型如何跑起来

src/deeplearning/transformer/mini_transformer_lm.cpp

  • TrainNextToken(...)：next-token 训练
  • Generate(...)：greedy 生成
  • GenerateSample(...)：采样生成
  • CalcNextTokenLoss(...) / CalcPerplexity(...)：评估

如果你想看数据是怎么准备的

  • BuildVocabularyFromText(...)：从文本构建词表

10 / 语言模型链路

这个项目里，Attention 最终是怎么变成“下一个字符预测”的

Attention 不会直接输出文字，它先输出“上下文感知后的表示”，再由语言模型头把这个表示投影到词表维度，最后才得到“下一个 token 是谁”的概率分布。

1

Tokenizer

把字符变成 token id。

2

Embedding

把离散 token 变成连续向量。

3

Attention / Block

让每个 token 读取上下文。

4

LM Head

把隐藏表示映射到词表打分。

5

Greedy / Sample

选出下一个 token。

真正要记住的是： attention 不是最终答案，它是“让模型得到更好的上下文表示”的方法。真正输出 token 的，是 attention 后面的语言模型头与采样策略。

11 / 总结

这套小项目现在已经能帮助你理解什么

如果你想学神经网络基础

看 NeuralNetwork 路线，理解权重、偏置、激活函数、loss、梯度下降、训练与预测。

如果你想学现代优化器

这不是工业级框架，但它已经足够揭示 attention 的核心机械结构。对于“想真正看懂原理”的人，这种可读、可跑、可改的小项目，往往比大框架更有教学价值。
