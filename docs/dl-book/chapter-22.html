强化学习:试错里学策略

从第 4 章到第 18 章,我们学的几乎都是 监督学习:每道题旁边都贴着标准答案,模型照着把损失降下来就行。 但世界上还有一大类问题——下棋、打游戏、机器人走路、甚至第 19 章里 RLHF 对齐大模型——没有逐条的“标准答案”,只有“这一步好不好”的反馈(奖励)。 这一章用大白话把强化学习(Reinforcement Learning, RL)的骨架搭起来, 让你读到 RLHF、PPO 时不再觉得它们是凭空冒出来的黑魔法。

读完这一章,你会明白

  • 监督学习与强化学习差在哪,为什么有些任务没法靠“标注答案”解决;
  • 状态、动作、奖励、策略、价值函数——RL 里五个最核心的词;
  • 探索与利用为什么永远是一对矛盾;
  • Q-learning、DQN、策略梯度、PPO 各自在解决什么问题;
  • 第 19 章 RLHF 第三步“用强化学习优化”到底在优化什么;
  • 本仓库没有 RL 训练代码,但前面学的神经网络怎样充当 RL 里的“大脑”。

1. 监督学习之外:只有“好不好”,没有“标准答案”

回忆第 0 章:监督学习像有老师批改作业——输入一封邮件,标签告诉你“垃圾/正常”; MNIST 给你一张图,标签告诉你“这是数字 7”。每一步都有明确的正确答案, 损失函数就是在量“离正确答案有多远”。

强化学习换了个设定:智能体(agent)在一个环境里不断做选择, 环境不告诉你“唯一正确答案”,只在你做完之后给一串奖励 signal——可能是 +1(吃到了金币)、-1(撞了墙)、 或者延迟很久才到的终局分数(棋局赢了 +1、输了 -1)。你的任务不是拟合标签,而是学一套出招习惯, 让长期累积奖励尽量大。

监督学习(本书主线)强化学习
训练信号每条样本有标签/目标值环境给的奖励(可延迟、可稀疏)
学什么输入 → 输出的映射在什么状态下采取什么动作(策略)
数据从哪来事先收集好的数据集智能体与环境互动时在线产生
典型例子MNIST、语言模型预测下一个 tokenAlphaGo、机器人控制、RLHF 对齐

2. 五样东西描述一个“游戏”:MDP

数学家把这类问题形式化成马尔可夫决策过程(MDP)。拆开就五个直觉概念: 状态 s(当前局面)、动作 a(你的选择)、 奖励 r(环境打分)、转移(下一步局面怎么变)、 折扣 γ(未来奖励打几折,0~1)。

回报 Gt = rt + γ rt+1 + γ² rt+2 + … RL 优化的是长期累积回报,不是眼前这一步

3. 策略与价值:到底想学什么?

  • 策略 π:在状态 s 下怎么出招,写成 π(a|s)。
  • 价值 V / Q:按当前策略走下去,长期能赚多少奖励;Q(s,a) 还多问一句“若先强行做 a 呢”。

4. 探索与利用

只选当前看起来最好的动作(利用),可能永远发现不了更好的路;一味乱试(探索)又浪费机会。 最简单的平衡是 ε-greedy:以概率 ε 随机试,以概率 1−ε 选当前最优。

5. Q-learning 与 DQN

状态不多时,把 Q(s,a) 存成表,用 Bellman 方程迭代更新。状态巨大时,用神经网络 近似 Q 函数——DQN。训练仍靠反向传播,只是标签来自试错而非人工标注。

6. 策略梯度与 PPO

动作空间巨大(如整个词表)时,直接学策略 πθ(a|s)更合适。 PPO在策略梯度上加裁剪和KL 惩罚,防止一次更新把语言能力毁掉—— 这正是第 19 章 RLHF 常用的算法。

RLHF 用 RL 语言怎么说?

状态 = 用户问题 + 已生成前缀;动作 = 下一个 token;奖励 = 整段写完由奖励模型打分; 策略 = 当前大模型;PPO = 提高高分回答的概率,同时 KL 拴住别偏离 SFT 参考模型太远。 训太狠会出现第 19 章说的对齐税——更安全听话,但创造性和部分能力可能下降。

小结

  • RL 靠奖励而非标准答案驱动,适合决策、控制、对齐。
  • MDP + 策略/价值 + 探索利用,是全部 RL 算法的共同语言。
  • 小状态用 Q-learning;大状态用 DQN;大动作空间用策略梯度/PPO。
  • RLHF 第三步就是把大模型当策略、奖励模型当裁判——读完本章再回头看第 19 章会顺很多。
