第 6 章 · 学习是怎么发生的

反向传播

第 5 章我们知道了“朝梯度反方向走”就能降低损失。可网络动辄成千上万个参数, 这么多梯度怎么算?反向传播(backpropagation)就是那个高效算法。 它常被传得很神秘,但其实只是一个东西:链式法则,加一点耐心。

读完这一章,你会明白

  • 链式法则的直觉:把“最终的错”一段段分配责任回去;
  • 配套速查图里每一块公式对应前向/反向哪一步、在代码里哪一行;
  • 反向传播的三步:从输出误差出发 → 逐层往回传 → 算出每个权重的梯度;
  • 为什么前向时要存下每层的 z(第 3 章那个伏笔);
  • 逐行读懂真实的反向传播实现。

1. 速查图走读:图里这个 demo 各项公式怎么用

下面这张配套速查图不是“公式大全”,而是同一个玩具网络从头到尾走一遍的备忘录。 我们按图上的五个区块,把它当成一个 mini demo 拆开讲:每一块公式,都对应前向算一次或反向算一次里的具体一步。

读下面五个小节时,可以一边看图里对应区域,一边往下翻。

① struct — 这个 demo 的网络长什么样?

图左上角画的是一张缩小版 MLP,和仓库里 MNIST 的 784→128→64→10 是同一类东西,只是故意画小方便手算:

  • 第 0 层(输入):2 个输入节点,前向时它们的值记作 out00、out01(也就是原始特征)。
  • 第 1 层(隐藏):2 个神经元,偏置叫 b10、b11。
  • 第 2 层(隐藏):2 个神经元,b20、b21。
  • 第 3 层(输出):1 个神经元 b30,输出 out30,拿去和 target 比。

连线的权重怎么读?图里 w100 表示:从输入 0 连到第 1 层 0 号神经元的那根线。 一般记法 w层号本层神经元上一层输入——三位数字分别对应“连到第几层 / 本层哪个神经元 / 上一层哪个输入”。 前向时数据从左往右流;反向时误差从 out30 往左传。

② base — 基础公式:前向和更新各干什么?

图中间 base 区列的是每次训练步都会用到的积木,按使用顺序理解最清楚:

图上的式子在 demo 里干什么对应章节 / 代码
Σ w·input + b = net 前向第 1 步:每个神经元先算“加权和 + 偏置”,得到激活前的值 net(书里常叫 z) 第 2 章 · neuron_preact_
sigmoid(net) = output 前向第 2 步:过激活函数,把 net 压到 (0,1),得到这一层输出,传给下一层当 input 第 2 章 · neuron_output_
S′(x) = S(x)(1−S(x)) 反向时要乘:链式法则里“output 对 net 的导数”。Sigmoid 两端平、中间陡,饱和区导数≈0 → 梯度容易消失 DerivActivate
Softmax 输出层若有多类(如 MNIST 的 10 类),把多个 net 变成概率分布。本图只有 1 个输出神经元,更常见是配 MSE;多分类 demo 见第 22 章 第 4 章
Etotal = ½n Σ|target−output|² 前向末尾:拿 out30 和 target 算 MSE,得到一个标量“错得多离谱” 第 4 章 · CalcLoss
∂E/∂out = −(1/n)(target−out) 反向起点:损失对输出层激活值的导数——预测比目标大,导数为负,告诉网络“该往下调” DerivLoss
w⁺ = w − η·∂E/∂w 反传之后:优化器按梯度更新权重;η 是学习率。反传只算 ∂E/∂w,真正改 w 是第 5 章的事 ApplyGradient

③ neuron — 以前向为例:神经元 b10 怎么算?

图里 neuron 区把上面两行公式钉在一个具体节点上。以第 1 层 0 号神经元为例:

net10 = out00·w100 + out01·w101 + b10
out10 = sigmoid(net10) 先线性组合,再激活——每个神经元都是这一套

把两个输入各自乘上连过来的权重,加上偏置,得到 net10;再套 sigmoid 得到 out10,供第 2 层使用。 在代码里,这就是第 3 章前向传播内层循环对每个神经元做的事: 先写 neuron_preact_,再写 neuron_output_。反向时要用到刚存下的 net10,所以前向不能省这一步。

④ formula — 反向通用式:δ 是什么?

图右侧 formula 区是不依赖具体下标的反向模板。先引入 δ(delta):某个神经元对最终损失负多少责。

  • 输出层:δo = ∂E/∂outo · S′(neto) — “损失对该神经元输出的影响”乘“激活有多敏感”。
  • 隐藏层:δl = ( Σo δo·wo ) · S′(netl) — 把后面一层传回来的责任,经权重汇总,再乘本层激活导数。
  • 权重梯度:∂E/∂w = δ · (连到这条边的上一层输入)。
  • 偏置梯度:∂E/∂b = δ — 偏置没有“另一端的输入”,责任就是它本身。

这四行就是下面§3 反向传播三步的公式版;读懂图,再读三步只是换了个叙述顺序。

⑤ example — 落到两根具体连线

图最右 example 区把模板代入本图的下标,这是最值得对照手算的两类情形:

情形 A · 输出层权重 w300(连 b30 的那根)

∂E/∂w300 = δ30 · out20
∂E/∂b30 = δ30 δ30 由 target 与 out30 算出;乘的输入是上一层神经元 20 的输出

输出层没有“更后面”的层,所以 δ30 直接从损失算起。 代码里对应 BackPropagationBatch 里先处理最后一层、再 grad_weight_[last][o][i] += d * in_vec[i] 那一支。

情形 B · 隐藏层权重 w100(连 b10 的那根)

δ10 = ( δ20·w200 + δ21·w210 ) · S′(net10)
∂E/∂w100 = δ10 · out00
∂E/∂b10 = δ10 隐藏层 δ 要先“汇总”后面所有连出去的边,再算这根 w 的梯度

和输出层不同,w100 的梯度不能一步写完:得先知道 δ10, 而 δ10 又依赖后面 b20、b21 传回来的责任——这就是为什么要从后往前一层层算。 代码里就是倒序循环 for (l = last-1; l >= 1; l--) 里那个 sum += weight * delta 累加,再乘 DerivActivate(preact, output)。

把 demo 和一次完整训练步对齐

前向:按 ③ 对每个神经元算 net、out(struct 整图走一遍) → 用 base 里的 MSE 算 E。
反向:用 base 里 ∂E/∂out 得输出层 δ(④) → 按 example B 从后往前传 hidden 的 δ → 按 example A/B 算每根 w、b 的梯度 → 用 w⁺ = w − η·∂E/∂w 更新(第 5 章)。
MNIST 只是把输入从 2 换成 784、层变宽,公式完全一样。

2. 链式法则:一段段地追责任

先看最简单的情形:一个参数 w,它影响 z,z 影响激活值 a, a 最终影响损失 L。这是一条“影响链”:

前向:w → z → a → L。反向:把 L 的误差,按每一段的局部导数连乘,传回 w。

要知道“w 动一点,L 会变多少”,链式法则说:把这条链上每一段的局部导数乘起来:

∂L∂w = ∂L∂a · ∂a∂z · ∂z∂w 总影响 = 损失对 a 的影响 × a 对 z 的影响 × z 对 w 的影响
一个类比

像追查一次生产事故的责任:最终的损失(成品报废)要追到某个工人(参数)头上, 得沿着流水线一站站往回问“你这一步对最终结果影响多大”,把这些“影响”乘起来, 就得到这个工人应负的总责任。反向传播,就是给每个参数同时做这件追责。

3. 反向传播的三步

把上面的思路推广到整张多层网络,就是干净利落的三步。我们引入一个中间量 δ(delta),表示“某个神经元对最终损失的责任”。

第一步:从输出层的误差开始

反向传播的起点是最后一层。它的 δ 由“损失对输出的导数”乘上“激活函数的导数”得到:

δ末层 = ∂L∂a · f′(z) 用到了第 4 章的 DerivLoss 和第 2 章的 DerivActivate

还记得第 4 章那个美妙巧合吗?如果用 softmax + 交叉熵,这一步直接简化成 δ = p − t。

第二步:把误差一层层往回传

有了后一层的 δ,前一层的 δ 就能算出来:把后一层的责任,按连接它们的权重“分摊”回来,再乘上本层激活的导数:

δl = ( Wl+1T δl+1 ) ⊙ f′(zl) ⊙ 表示逐元素相乘;WT 是把权重“反过来用”,把后层责任分回前层

第三步:用 δ 算出每个参数的梯度

一旦每个神经元都有了自己的 δ,梯度就唾手可得——权重的梯度,就是“它两端的 δ 和输入”的乘积:

∂L∂wl,o,i = δl,o · al−1,i      ∂L∂bl,o = δl,o 权重梯度 = 本神经元的 δ × 上一层对应的输入;偏置梯度就是 δ 本身

5. 逐行读懂反向传播

真实代码就是上面三步的忠实翻译。第一步:末层的 δ。

第二步:把 δ 一层层往回传。

第三步:用 δ 把梯度累加出来。

前向 + 反向 = 一次完整的训练步

把这一章和前几章串起来:前向算出预测(第 3 章)→ 损失衡量错误(第 4 章)→ 反向算出每个参数的梯度(本章)→ 优化器按梯度更新参数(第 5 章)。 这四步循环成千上万次,网络就“学”会了。这就是第 0 章那个训练循环的完整真相。

常见误区:反向传播 ≠ 更新参数

反向传播只做一件事——算出每个参数的梯度(“该往哪调、调多少”的建议)。 至于真正怎么挪参数,是优化器的活儿(第 8 章):SGD 直接 w −= 学习率 × 梯度, Adam 则用动量 + 自适应步长。所以“反传”和“更新”是两个步骤,别混为一谈—— 在很多框架里它们也确实是分开的两次调用(先 backward() 求梯度,再 optimizer.step() 更新)。

小结

  • 配套速查图五块:struct 看结构,base/neuron 看前向,formula/example 看反向,最后 w⁺ 才是更新。
  • 反向传播 = 链式法则:把“最终损失”按每段局部导数连乘,分配责任回每个参数。
  • 三步:① 末层 δ = ∂L/∂a · f′(z)(softmax+CE 时就是 p−t);② 逐层回传 δl = (WTδ) ⊙ f′(z);③ 梯度 = δ × 输入。
  • 反向时要用前向存下的 z(neuron_preact_)来算激活导数。
  • 前向 → 损失 → 反向 → 更新,四步一循环,反复多次即为训练。

动手与思考

问题 1:为什么叫“反向”传播?

因为计算方向和前向相反:前向是数据从输入流到输出;反向是误差(δ)从输出层一层层流回输入层。代码里那句 for (l = last-1; l >= 1; l--) 的倒序循环就是它的体现。

问题 2:速查图里 ∂E/∂w100 为什么要先算 δ10?

w100 在隐藏层,δ10 不是直接从损失来的,要把后面 b20、b21 的责任经 w200、w210 汇总回来,再乘 S′(net10)。有了 δ10 才能乘输入 out00 得到这根权重的梯度。

问题 3:权重 wl,o,i 的梯度由哪两样东西相乘得到?

由“这个权重指向的神经元的 δ(neuron_delta_[l][o])”乘以“它接收的那个输入(上一层的输出 in_vec[i])”。直觉:责任越大、输入越强,这个权重就该调得越多。

问题 4:如果前向时没有保存每层的 z,反向传播会怎样?

很多激活函数(尤其 GELU)的导数需要原始的 z 才能算准,缺了它就只能用粗略近似,梯度不准、训练变差。所以前向时顺手把 z 存进 neuron_preact_ 是必要的。

反向传播搞定,“学习”的完整闭环就通了。但同一条链路里,用哪种激活函数会直接影响梯度好不好传。 下一章我们就把 Sigmoid、ReLU、GELU 这些激活函数摆到一起,看它们的曲线、导数和各自的脾气。
