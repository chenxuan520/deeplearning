第 6 章 · 学习是怎么发生的

让它真的训得动

前向、损失、反向、梯度下降——“学习”的原理已经讲完了。但把原理变成 真能训练成功的模型,中间还隔着一整套工程技巧。 这一章我们把四样最重要的配齐:好的初始化、聪明的优化器、会变化的学习率、防爆炸的梯度裁剪。 它们就是现代深度学习的“标准启动套件”。

读完这一章,你会明白

  • 为什么参数不能初始化成全 0,He/Xavier 初始化在解决什么;
  • 优化器从 SGD → Momentum → Adam → AdamW 一路在补什么短板;
  • 学习率为什么要“先热身、再退火”,以及 warmup + cosine 长什么样;
  • 梯度裁剪和 weight decay 分别防的是什么问题。

1. 起点很重要:参数初始化

训练前,所有权重得有个初始值。你可能想:全设成 0 不是最干净吗? 恰恰是最糟的。如果一层里每个神经元的权重都一样,它们收到的输入一样、 算出的输出一样、反传回来的梯度也一样,于是永远保持相同—— 这一层等于只有一个神经元在工作。这叫对称性问题,必须用随机初始化打破。

但随机也有讲究:初始值太大,信号逐层放大直到“爆炸”;太小,信号逐层衰减直到“消失”。 诀窍是让每层输出的“波动幅度”大致稳定。He 初始化(配 ReLU 类激活)和 Xavier 初始化(配 Sigmoid/Tanh)就是按这一层的输入个数(fan-in)来定随机范围:

limit = √( 6 / fan_in ),   w ~ Uniform(−limit, +limit) 输入越多,初始权重就调得越小,避免求和后数值过大

2. 优化器进化史:从 SGD 到 AdamW

第 4 章的朴素 SGD(w ← w − η·梯度)能用,但有两个毛病:在“狭长峡谷”地形里来回横跳,在“平坦”地段又走得太慢。后面几代优化器,就是在逐个修补它。

第一步加“惯性”:Momentum

Momentum(动量)给参数更新加上惯性:像一个滚下山的球,会累积“速度”。 这样同方向的梯度会越滚越快(冲过平地),来回抖动的方向则相互抵消(峡谷里更稳)。

第二步给每个参数“私人步长”:Adam

不同参数的梯度大小可能天差地别,用同一个学习率不公平。Adam 同时维护两样东西: 一阶矩 m(梯度的滑动平均,代表“惯性/方向”)和二阶矩 v(梯度平方的滑动平均,代表“最近这个参数有多活跃”), 再用 v 给每个参数自适应地缩放步长:

m ← β1m + (1−β1)g     v ← β2v + (1−β2)g2
m̂ = m / (1−β1t)     v̂ = v / (1−β2t)
Δw = η · m̂ / ( √v̂ + ε ) 方向用 m,步长被 √v 自动缩放;m̂ / v̂ 是“偏差修正”,弥补训练初期 m、v 从 0 起步的冷启动

第三步把正则“解耦”:AdamW

weight decay(权重衰减)是把权重轻轻往 0 拉,抑制过拟合。经典 Adam 把它混进梯度里 (g += wd·w),但这样会被自适应步长削弱,效果打折。AdamW 的改良是: 自适应那部分照算,weight decay 单独、直接地作用在权重上(解耦),所以训 Transformer 时是标配。

3. 学习率不必一成不变:调度器

第 4 章我们用固定学习率,但更聪明的做法是让它随训练进程变化:

  • Warmup(热身):开头几步用很小的学习率慢慢升上来,避免刚开始参数还很乱时一脚踩空、直接训崩;
  • Cosine 退火:热身之后,让学习率沿着余弦曲线平滑地降到一个很小的值,后期小步精修,稳稳落进谷底。

先线性热身到峰值(黄),再沿余弦曲线平滑退火到最小值(蓝)。

小结

  • 初始化:不能全 0(对称性);随机且按 fan-in 缩放(He/Xavier),避免信号爆炸或消失。
  • 优化器:SGD → 加惯性的 Momentum → 自适应步长的 Adam → 解耦正则的 AdamW。
  • 学习率调度:warmup 热身防早期训崩,cosine 退火让后期稳稳收敛。
  • 梯度裁剪:给梯度大小设上限,防止某一步爆炸把训练带飞;weight decay 抑制过拟合。

动手与思考

问题 1:为什么把所有权重初始化为 0 是个坏主意?

会导致同一层所有神经元完全对称:输入、输出、梯度都一样,更新后仍然一样,等于整层只有一个神经元在学。必须用随机初始化打破这种对称性。

问题 2:Adam 里的二阶矩 v 起什么作用?

v 是梯度平方的滑动平均,衡量某个参数“最近有多活跃”。更新时除以 √v,相当于给每个参数一个自适应步长:梯度一直很大的参数自动用更小的步长,更稳。

问题 3:训练到一半损失突然变成 NaN,除了调小学习率,还能开什么开关?

开梯度裁剪(set_gradient_clip_norm)。它给梯度总长度设上限,防止某一步出现异常巨大的梯度把参数推飞。配合 warmup 也能缓解早期的不稳定。
