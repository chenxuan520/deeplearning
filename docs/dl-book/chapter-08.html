第 8 章 · 序列与 Transformer

注意力机制

上一章我们想通了“为什么要让每个词直接看全局”。这一章把这台机器彻底拆开: Q、K、V 三个角色,打分,softmax,加权求和。 这套机制是整个 Transformer、乃至今天所有大模型的发动机。别担心,它其实就是 “带权重的查字典”,你前面学的点积、softmax、加权和在这里全用得上。

读完这一章,你会明白

  • Q(查询)、K(键)、V(值)分别是什么,为什么要有这三样;
  • 注意力的完整流程:打分 → 缩放 → softmax → 加权求和;
  • causal mask(因果掩码)是怎么让模型“不能偷看未来”的;
  • 多头注意力为什么有用,并逐行读懂真实的 self-attention 实现。

1. 三个角色:Query、Key、Value

注意力把“查资料”这件事拆成了三个角色。还是用查字典/搜索的类比:

  • Query 查询当前这个词“我想找什么”。比如“它”想找它指代的对象。
  • Key 键每个词对外挂出的“标签 / 索引”,用来被匹配。像每本书的标题。
  • Value 值每个词真正的“内容”,一旦被选中就把它取出来用。像书里的内容。

关键点:这三样都是从同一份输入词向量,分别乘上三个不同的权重矩阵 WQ、WK、WV 得到的。 换句话说,每个词都同时准备好了自己的“问题、标签、内容”三副面孔。

2. 完整流程:打分 → 缩放 → softmax → 加权求和

对某一个 query 词,注意力做四件事:

  1. 打分:拿它的 Query 和每个词的 Key 做点积。点积越大,说明越“匹配”、越相关。(点积就是第 8 章……其实你在第 1 章加权求和里就见过它了。)
  2. 缩放:把分数除以 √d(d 是向量维度)。维度一大,点积容易变得很大,会把 softmax 推到极端,缩放能让它稳一点。
  3. softmax:把一排分数变成一排加起来等于 1 的权重(第 3 章学过)。这就是“注意力分配”。
  4. 加权求和:用这排权重,对所有词的 Value 做加权求和,得到这个 query 的新表示——一个“看过全局、按相关性融合”的向量。

4. 不能偷看未来:causal mask

语言模型要做的事是“根据前文预测下一个词”。训练和生成时,有一条铁律: 预测第 t 个词时,只能看第 1 到 t 个词,绝不能看到它后面的词 ——否则就是“偷看答案”,学不到真本事。

实现办法很巧妙:在打分之后,把所有“未来位置”的分数设成负无穷。 这样它们一过 softmax 就变成约等于 0 的权重,相当于被彻底屏蔽。这就是 causal mask(因果掩码)。(在上面的实验台里勾选 causal,就能看到后面的词被标成 masked。)

5. 多头注意力:几个视角一起看

单头注意力只有一种关注视角。但一句话里,词与词的关系是多维度的: 有的是“主语—谓语”,有的是“动词—宾语”,有的是“位置相邻”。 多头注意力(multi-head attention)的想法是: 把向量切成几段,每一段(每个“头”)独立做一次注意力,各自学一种关系,最后再拼起来。

维度怎么分

如果模型维度是 d=64、头数是 8,那每个头分到 d/8 = 8 维。 代码里就是 head_dim_ = model_dim_ / head_num_,每个头在自己负责的那一段维度上独立运算,互不干扰。

切换不同的头,观察它们关注的模式截然不同——这正是多头的价值。

回头看,全是老朋友

注意力听起来高大上,但拆开后:点积(第 1 章加权求和)、softmax(第 3 章)、 加权求和(还是第 1 章)。它真正的新意只有一个—— 让权重由“Query 和 Key 的相关性”当场算出来,而不是固定写死。

小结

  • 每个词从输入算出三副面孔:Query(我找什么)、Key(我的标签)、Value(我的内容)。
  • 流程:Q 和每个 K 点积打分 → 除以 √d 缩放 → softmax 成权重 → 对 V 加权求和。
  • causal mask 把“未来位置”的分数设为 −∞,确保模型预测时不能偷看后文。
  • 多头 = 把维度切成几段,每段独立做注意力,学不同关系,最后拼接 + 输出投影融合。
  • self-attention 的“self”指 Q/K/V 都来自同一序列。

动手与思考

问题 1:打分用的是 Query 和 Key 的点积,为什么点积能衡量“相关性”?

点积越大,说明两个向量方向越一致、越“合拍”。所以当某个词的 Key 和当前 Query 方向相近时,点积大、得分高,注意力就更多地分给它。

问题 2:为什么要除以 √d?

维度 d 越大,点积的数值越容易变得很大,会把 softmax 推到极端(几乎全押在一个词上,梯度也变小)。除以 √d 把分数拉回合理范围,训练更稳定。

问题 3:causal mask 是怎么实现“看不到未来”的?

在打分阶段,把所有“未来位置”的分数设成负无穷;经过 softmax 后它们的权重≈0,等于完全不参与加权求和,于是模型只能依赖当前位置及之前的词。
