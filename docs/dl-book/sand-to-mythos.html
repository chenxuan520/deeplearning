第 一 幕

物质,变成开关

一块石头凭什么能算数?因为人类学会了让一小片硅,在"通"与"断"之间听话地切换。

第一幕 · 物质约数十亿年前

一粒沙子

故事的起点,是海滩上最不起眼的东西:沙。

地壳形成以来,硅就是地表含量第二高的元素,大量以二氧化硅(SiO₂)的形式躺在沙子里。
沙的主要成分是硅和氧牢牢锁成的晶体。提纯后的单晶硅,原子排列整齐、性质稳定,是天然的"计算基材"。
芯片、神经网络、大模型,追到最底层都要有一种又便宜又可控的材料——硅正好是。
第一幕 · 物质19 世纪 · 法拉第等

半导体:关键是可变

硅的价值不在"能导电",而在它能被操控导不导电。

19 世纪起,人们陆续发现某些材料的导电性会随温度、光照、杂质剧烈变化——"半导体"由此得名。
纯硅每个原子有 4 个价电子,刚好互相锁死,几乎不导电;但只要外界轻轻一推(电场、杂质),它就能翻面变导体。
金属永远导电、橡胶永远绝缘,都没法"控制"。只有能在通/断之间切换的材料,才能拿来做开关、做计算。
第一幕 · 物质20 世纪初

掺杂:给硅一个倾向

纯硅太"中立"。人为掺入杂质,才让它有了性格。

20 世纪初半导体物理成熟后,"掺杂"成为可控工艺,为后来的二极管、三极管铺路。
掺入磷 → 多出自由电子,成 N 型(带负载流子);掺入硼 → 多出空位,成 P 型(带正载流子)。
要"控制"电流,先得有不对称:一边想给电子、一边想要电子。把两者贴一起,才有可操纵的边界。
第一幕 · 物质1940s · PN 结

二极管:电流只走一个方向

把 N 和 P 贴在一起,交界处诞生了第一个"规则"。

1904 年真空管二极管问世;后来半导体 PN 结二极管取而代之,更小更省电。
PN 交界形成"内建电场"。正向偏置会削弱势垒 → 容易导通;反向偏置会加宽耗尽层 → 近似阻断。这就是"正向通、反向断"。
电流第一次被物理规则"驯服"成单行道。但它只会认死方向,不能被外部信号控制——还差一只"手"。
第一幕 · 物质1947 · 贝尔实验室

三极管:用电流控制电流

整段历史里最关键的一次发明,就发生在这一年。

1947 年冬,贝尔实验室做出第一只晶体管,三位发明者后来拿了诺贝尔物理学奖。
三层掺杂(NPN)。基极一点微小电流,就能控制集电极大得多的电流——像用细水管的阀门,控制主管道的洪流。
它同时是放大器和可被信号控制的开关。可控开关 = 现代计算的最小积木,一切从这里起。
第一幕 → 第二幕抽象层

0 和 1:开关的两种姿态

从物理到信息,只差最后这一步抽象。

与晶体管普及同步——1940s 起,布尔代数与二进制成为数字电路的通用语言。
规定:低电压 = 0,高电压 = 1。一个晶体管的"断/通",就是一个比特。
用两个离散值(而非连续电压)最抗噪、可堆叠。从此文字、图像、声音,原则上都能写成一长串 0 和 1。

第 二 幕

开关,变成机器

单个开关什么也不是。可当亿万个开关按规则连起来、还学会了记忆和节拍,它们就成了一台会执行指令的计算机。

第二幕 · 机器1930s–1950s

门电路:开关学会判断

几个晶体管一组合,就能表达"逻辑"。

1930s 香农指出布尔逻辑可用开关电路实现;1950s 晶体管门电路成为造计算机的标准砖块。
用晶体管搭出与(AND)、或(OR)、非(NOT):输入是 0/1,输出也是 0/1,对应"且、或、取反"。
任何复杂逻辑都能拆成这三种门的组合。它们是数字世界的原子。
第二幕 · 机器1950s

加法器:逻辑开始算术

门电路一接,"计算"就冒出来了。

随门电路成熟,半加器/全加器成为运算单元(ALU)的核心零件。
一位加法:XOR 算出本位和,AND 算出进位。串起多位,就能做任意大数相加。
加减乘除最终都能归约为加法 + 移位。机器的"算"能力,就是从这几个门里长出来的。
第二幕 · 机器1950s

锁存器:电路第一次记住

会算还不够,机器还得会"记住刚才"。

与门电路同期成熟,是寄存器、内存的最小记忆单元。
把两个门首尾相接成反馈环,输出绕回输入,电路就会"咬住"当前这一位——输入撤走也不忘。
有记忆,才谈得上"状态"。会记住 = 从计算器迈向计算机的分水岭。
第二幕 · 机器1950s–1960s

触发器与时钟

让亿万个记忆单元整齐划一地前进,靠的是一个节拍。

触发器在 1950s–60s 成为时序电路标准件;晶振时钟同期成为同步电路的心跳。
触发器 = 带"闸门"的锁存器,只在时钟跳变的那一瞬才采样输入、更新输出;晶振把时间切成等长的一格格。
若各单元各改各的,信号会乱套。统一节拍让全芯片同步推进一步;周期越短越快,但发热越大——这就是"主频"。
第二幕 · 机器1960s–1980s

流水线:五步接力

让一条指令分几步走,还能同时处理好几条。

1960s 大型机引入流水线,1980s 起成为几乎所有 CPU 的标配。
一条指令拆成取指→译码→执行→访存→写回,各阶段用触发器隔开、按时钟推进,像工厂流水线。
前一条还在"执行",后一条已经在"取指"。五个工位同时忙,吞吐大幅提升——不必等一条走完再开始下一条。
第二幕 · 机器1945 起

冯诺依曼:程序也是数据

为什么一台电脑能装任何软件?答案在 1945 年的一份草稿里。

1945 年,冯·诺依曼在 EDVAC 报告里提出"存储程序"结构,沿用至今。
CPU + 内存 + 输入输出。关键是指令和数据放在同一片内存里,CPU 按地址取指令、执行。
程序本身也是数据,就能被加载、替换、生成。机器不再为单一任务焊死——通用计算机由此诞生。
第二幕 · 收束1971 · Intel 4004

芯片:硅上长出一座城

所有这些,最终被压进指甲盖大的一块硅。

1971 年 Intel 4004 面世,第一枚商用微处理器,2300 个晶体管。
光刻工艺把门电路、寄存器、流水线全部集成到一片硅上,取指-译码-执行装进单枚芯片。
集成度越高,越小、越快、越便宜(摩尔定律)。开关终于长成了机器——接下来,该谈算力了。
第二幕 → 第三幕表示层

并行:机器开始吞吐

一台机器不只要会执行指令,还要能把同一种运算铺开来同时做。

从流水线、向量处理器到 GPU,计算机逐渐从"单条指令跑得快"走向海量任务一起跑。
把大任务拆成许多彼此独立的小乘加,交给大量计算单元同时执行。时间不再只靠主频压缩,也靠并行度摊薄。
神经网络最吃的正是重复、规整、可并行的矩阵运算。机器结构在这里转化成了真正的算力。

第 三 幕

机器,变成算力

CPU 擅长一步步地"想"。可有一天人们发现:让智能长出来,需要的不是一个聪明大脑,而是同时算完千万道乘法的蛮力。

第三幕 · 算力1980s–2000s

CPU 与 GPU

两种芯片,两种哲学:一个求快,一个求多。

CPU 在 1980s–90s 走向多核与高主频;GPU 于 1999 年前后从图形加速卡演化而来。
CPU:少数强核 + 大缓存,擅长复杂串行逻辑、低延迟决策。GPU:上万个简单核,擅长海量互不依赖的乘加同时算。
神经网络要的不是一条聪明路径,而是矩阵洪流。GPU 天生对口——这是后来一切的算力前提。
第 29 章 · 从沙子到 CPU/GPU
第三幕 · 算力2006 · NVIDIA CUDA

CUDA:让显卡不止渲染画面

GPU 本是显卡——生来只为渲染游戏和 3D 画面。CUDA 把这身蛮力,交到了所有程序员手里。

2006 年 NVIDIA 发布 CUDA。在此之前,想用 GPU 算别的,得把数据伪装成图像、借渲染管线偷偷算,极其别扭。
CUDA 提供一套通用编程模型,让你直接把成千上万个线程铺到 GPU 核心上做并行计算,不必再假装在画图。
于是 GPU 从"游戏显卡"变成"通用算力机"。深度学习一直缺的最后一块拼图——便宜、海量、可编程的并行算力——就位了。
第三幕 → 第四幕表示层

矩阵:一切都变成一张表

GPU 擅长的"洪流",到底是什么形状?

从第一个神经网络起,矩阵乘法就是核心运算,GPU 时代更被推到极致。
图像、文字、声音先被编码成数字阵列;网络每一层做的,就是矩阵 × 矩阵 再加激活。
矩阵乘 = 海量、规整、互不依赖的乘加,正是 GPU 的主场。算法与算力在此合流。

第 四 幕

算力,变成学习

有了海量算力,还要有一种机制:不靠人写死规则,而是让机器自己从错误里,把亿万个参数一点点调对。

第四幕 · 学习1943 / 1958

神经元:数字有了倾向

最小的"会判断"的单元,只是一道加权求和。

1943 年 McCulloch-Pitts 提出人工神经元;1958 年 Rosenblatt 的感知机让它能被训练。
把输入按权重加起来、加个偏置,再过一道激活函数决定"点亮多少"。就这么简单。
权重可调,意味着这颗单元的"判断倾向"能被学习。它是从"算数"跨到"智能"的第一块积木。
第 2 章 · 一个神经元
第四幕 · 学习1986 · Rumelhart 等

反向传播:让错误回流

网络怎么知道每个权重该往哪调?让误差自己走回去。

1986 年论文让反向传播广为人知,成为训练多层网络的标准算法。
先前向算出预测与答案的差距(损失),再用链式法则把这个差距逐层反传,得到每个权重的"该调多少"。
这让学习变成一件自动、可规模化的事:不用人设计规则,喂数据、算误差、反传、微调,重复亿万次。
第 6 章 · 反向传播
第四幕 · 学习1998

MNIST:让训练看得见

抽象的"学习",在这个任务里第一次能亲手跑通。

1998 年 LeCun 整理出 MNIST 手写数字集,至今仍是入门第一课。
一张 28×28 的图 → 展平成向量 → 过几层网络 → 输出 10 个数字的概率 → 反传训练。
它把"数据→建网→训练→评估"这条完整闭环压到最小,让人看清网络是怎么一步步学对的。
第 23 章 · MNIST 实战
第四幕 · 学习2012 · ImageNet

AlexNet:深度学习引爆

神经元、反向传播、闭环都有了——就差一次让全世界相信的胜利。

2012 年,AlexNet 在 ImageNet 图像识别竞赛上把错误率断崖式拉低,一举夺冠。
还是神经元 + 反向传播那一套,只是网络更深、跑在两块 GPU 上、喂了上百万张标注图——算法 + 算力 + 数据三合一。
它证明了:只要算力和数据够,"让机器自己学特征"能碾压人工设计。这一枪,点燃了通往大模型的整条路。
第四幕 · 学习2013 · word2vec

词嵌入:词有了坐标

图能被计算,那"词"呢?先把词变成向量。

2013 年 word2vec 让"词向量"变得实用、流行。
用"上下文预测词"来训练,把每个词压成一个稠密向量。意思相近的词,向量也相近。
语言得先变成数字,网络才能算。而且向量能做运算:国王 − 男人 + 女人 ≈ 女王——语义有了方向。
第 15 章 · 词嵌入与 word2vec
第四幕 → 第五幕1997 · LSTM

序列模型:按时间读句子

一句话有先后顺序。怎么让机器"边读边记"?

RNN 上世纪就有,1997 年 LSTM 缓解遗忘;2014 年前后成为机器翻译主力。
维护一个隐藏状态,每读一个词就更新它、再传给下一步——像滚雪球一样带着上下文往前走。
但它串行、且会遗忘:读到句尾,句首的信息常常稀释殆尽。长距离依赖,成了必须翻过的墙。
第 14 章 · RNN 与 LSTM
第四幕 → 第五幕表示层

Token:语言切成积木

机器不能直接读"意思"。它先把语言切开,再把每一块映射成数字。

从词向量到现代语言模型,文本都要先被分词或切成 token,再进入神经网络。
一句话被拆成 token ID,每个 ID 查表得到向量。模型真正处理的不是汉字或英文单词,而是一串可计算的向量积木。
Token 把开放的语言世界压成有限词表,又保留组合能力。学习到这里,终于能迈进语言这一幕。

第 五 幕

学习,变成语言

2017 年一个想法改变了一切:让每个词直接看向所有词。从此规模、数据、算力叠加起来,机器开始像懂了语言。

第五幕 · 语言2017 · Attention Is All You Need

注意力:意义来自关系

与其一个字一个字顺着记,不如让每个词直接看向全句。

2017 年论文《Attention Is All You Need》提出自注意力,一举甩开 RNN。
每个词生成 Query/Key/Value,和句中所有词算相关性打分,再按分数加权汇总信息。
远近不再是障碍——任意两词一步直连,还能并行计算。这解决了 RNN 的遗忘和串行两大痛点。
第 17 章 · 注意力机制
第五幕 · 语言2017

Transformer:可堆叠的积木

把注意力包成一块标准件,就能无限往上摞。

2017 年同一篇论文提出 Transformer,成为此后所有大模型的骨架。
一块 = 注意力 + 残差连接 + LayerNorm + 前馈网络。残差和归一化让深层可训练不发散。
结构统一、可无限堆叠、天然并行——这正是"越大越强"能成立的工程前提。
第 18 章 · Transformer 的完整结构
第五幕 · 语言2018–2019 · GPT / BERT

语言模型:预测下一个词

目标简单到近乎朴素,能力却从中长了出来。

2018–2019 年,GPT、BERT 等把 Transformer 用于大规模语言建模。
给定前文,预测下一个 token 的概率分布,用交叉熵训练。答案就藏在文本本身(自监督)。
答案免费,就能拿整个互联网来训。在海量文本上练"猜下一个词",通用语言能力竟自己浮现。
第 19 章 · 字符级语言模型
第五幕 · 语言2018 → 2022 · OpenAI

GPT:把这条路推到底

同样是"预测下一个词",OpenAI 只做一件事——把它拼命做大。

2018 年 GPT-1,2019 年 GPT-2,2020 年 GPT-3(1750 亿参数);2022 年底 ChatGPT 让全世界第一次亲手用上大模型。
只保留 Transformer 的解码器(decoder-only)、带因果掩码,一路自回归地预测下一个 token;参数、数据、算力逐代指数级放大。
它用最直接的方式证明:不换算法,只堆规模,模型就能从"续写"长出对话、推理、写代码的能力。大模型时代由此进入公众视野。
第 20 章 · 通往大模型
第五幕 · 语言2020 · Kaplan / Chinchilla

规模定律:大力真的出奇迹

"堆大"不是蛮干,它背后有一条可预测的曲线。

2020 年起,一系列研究(含 Chinchilla)量化了规模与效果的关系。
同时放大参数、数据、算力,测试损失沿一条平滑曲线持续下降;越过门槛,新能力还会涌现。
正因为可预测,才敢在砸下千万美元前,用小模型把曲线画出来外推——这把"炼大模型"变成了工程决策。
第 20 章 · 规模化
第五幕 · 语言2022 起

大规模训练:模型是"炼"出来的

一个可用的大模型,要分好几个阶段"炼"。

2022 年 ChatGPT 之后,"预训练 + 后训练"成为大模型产品的标准流程。
预训练读遍海量文本学通用能力;SFT 用指令数据教它听话;RLHF 按人类偏好对齐;必要时再蒸馏成小模型。
