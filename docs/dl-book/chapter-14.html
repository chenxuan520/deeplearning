第 14 章 · 经典网络结构

词嵌入与 word2vec

不管是 RNN 还是后面的 Transformer,处理文字前都得先把词变成向量。可“词”本是一个个 离散符号,怎么变成有含义的数字?这一章讲词嵌入(embedding)—— 让每个词第一次拥有自己的“语义坐标”,意思相近的词,坐标也相近。

读完这一章,你会明白

  • 为什么最朴素的 one-hot 表示又浪费又不懂语义;
  • 分布式表示:用一个稠密向量当词的“语义坐标”;
  • 怎么用点积/余弦衡量两个词有多相近(回到第 1 章);
  • word2vec 怎么靠“看上下文”把词向量学出来(CBOW / skip-gram);
  • 为什么会有 国王−男人+女人≈女王 这种神奇的向量算术,以及它和大模型 embedding 层的关系。

1. 计算机只认数字:先看最笨的 one-hot

词是符号,得先编码成数字。最直接的办法是one-hot:词表里有 V 个词, 就用一个长度 V 的向量,只有这个词对应的位置是 1,其余全是 0。 比如词表 [猫, 狗, 苹果],那“狗” = [0, 1, 0]。

2. one-hot 的两个毛病

  • 维度爆炸、极其稀疏:真实词表动辄几万几十万,每个词就是一个几万维、只有一个 1 的向量,又大又空。
  • 完全不懂语义:任意两个不同词的向量都互相垂直,点积恒为 0(第 1 章)。也就是说,在 one-hot 眼里, “猫”和“狗”的相似度,跟“猫”和“苹果”的相似度一样都是 0——它把词与词之间的关系全丢了。
我们真正想要的

一种又短又懂语义的表示:维度不大(几百维),而且意思相近的词,向量也相近 (“猫”和“狗”应该离得近,“猫”和“苹果”离得远)。这就是词嵌入。

3. 分布式表示:给词一个“语义坐标”

词嵌入把每个词表示成一个稠密的低维向量(比如 300 维,每一维都是有意义的小数)。 怎么用几个数字表示一个复杂事物?你其实早会了——屏幕上任何颜色都用 RGB 三个数表示, 相近的颜色三个数也相近。词嵌入一模一样,只是维度更高:用一串数字表示一个词的“意思”,意思越近,向量越近。

4. 语义相近 = 向量相近

有了向量,就能用第 1 章的点积 / 余弦相似度衡量两个词有多像:方向越接近,越相似。 训练的目标,就是把语义相近的词“挤”到相近的方向上。画到二维平面上,大概是这样:

在训练好的词空间里,“猫/狗”聚成一堆;而“男人→国王”和“女人→女王”竟是平行的——语义关系变成了几何关系。

5. word2vec:靠“上下文”把词向量学出来

这些向量不是人手工标的,而是训练学出来的。经典方法 word2vec 基于一个朴素假设—— “看它跟谁在一起,就知道它是什么”(近朱者赤):经常出现在相似上下文里的词,意思也相近。 它把这变成一个“完形填空”式的预测任务,用海量文本自监督地训练:

  • CBOW用上下文猜中心词:遮住中间的词,拿两边的词去预测它(“我 __ 了一杯咖啡” → “喝”)。
  • skip-gram反过来,用中心词猜上下文:给“喝”,预测它周围可能出现“咖啡/水/酒”。

训练中,为了把这些完形填空做对,模型被迫把常出现在相似语境的词,调整到相近的向量方向—— 语义就这样“无中生有”地长了出来。这其实就是第 11 章说的自监督:答案(被遮的词)文本里现成就有,不用人标。

6. 神奇的向量算术

训练好的词向量有个令人惊艳的性质:语义关系变成了可以加减的几何关系。最著名的例子:

向量(国王) − 向量(男人) + 向量(女人) ≈ 向量(女王) “去掉男性、加上女性”,国王就平移成了女王——正是上图那两条平行箭头

类似地还有 北京 − 中国 + 日本 ≈ 东京。这说明词向量不只是“相近词靠近”,还编码了可组合的语义维度 (性别、首都关系……)。一个只是为了“完形填空”而训练出来的副产品,却学到了如此结构化的语义,这也是深度学习最迷人的地方之一。

7. 从 word2vec 到大模型的 embedding 层

今天的大模型里,词嵌入以embedding 层的形式存在:它就是一张可学习的查找表—— 每个 token 的 id 对应表里的一行向量(第 18 章会看到它的代码)。有两点值得记住:

  • 可以“拿来就用”:别人在海量语料上训好的词向量(如经典的 GloVe)能直接下载复用,这叫迁移学习——省掉从零训练的巨大成本。
  • 在大模型里是端到端一起训的:embedding 表不再单独训练,而是和整个网络一起,被“预测下一个词”的损失顺带优化(第 18、19 章)。原理没变,还是“靠上下文学语义”。
一条线串起来

one-hot(离散、无语义)→ 词嵌入(稠密、有语义坐标)→ 用点积比相似度(第 1 章)→ 注意力用 Q·K 打分(第 16 章)→ 大模型的 embedding 层(第 18 章)。词向量,是整条 NLP 链路的起点。

小结

  • one-hot 又大又空,且任意两词都正交、毫无相似度——丢了语义。
  • 词嵌入用稠密低维向量当“语义坐标”,意思相近 → 向量相近(点积/余弦衡量)。
  • word2vec 基于“近朱者赤”,用 CBOW/skip-gram 的完形填空自监督地学出词向量。
  • 词向量能做算术:国王−男人+女人≈女王,语义关系变成几何关系。
  • 大模型的 embedding 层就是可学习查找表,可迁移复用,也可端到端一起训。

词有了语义坐标,序列有了 RNN——但 RNN 那两个硬伤(记不住远处、不能并行)还悬着。 下一部分,我们正式请出解决这一切的主角:注意力。先看它到底要解决什么问题。
